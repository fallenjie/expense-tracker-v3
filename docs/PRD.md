# PRD-001 记账 app V3

## 背景
基于 v1/v2 经验教训，重新设计精品版。核心变化：从「设置」Tab 改为「我的」Tab，新增账户余额自动计算功能，技术方案不变（纯 localStorage，H5）。

## 需求来源
- 飞书文档：https://www.feishu.cn/docx/FH1ldfbhtobLjex3GggclZganjc
- 群内讨论（2026-04-29）

## 功能需求

### FR-01 页面结构（4 Tab）
- **首页**：今日收支概览 + 预算进度 + 快捷记账按钮
- **账单**：搜索 + 时间/分类/账户筛选
- **报表**：日报 + 月报，支出+收入双饼图
- **我的**：账户管理 + 预算设置 + 数据导出 + 退出登录

### FR-02 首页
- 支出卡片（红色大字）+ 收入卡片（绿色大字）+ 结余，分开独立显示
- 月度预算进度条（4色：绿→黄→橙→红）
- 右下角悬浮「+记一笔」圆形按钮，点击弹出记账表单

### FR-03 记账流程
- 表单顶部：最近使用分类（最多3个）快捷 chip
- 智能记忆：记住上次「分类+类型+账户」组合，自动填充
- 金额输入：增加 ×100 / ×1000 / ×10000 快捷按钮
- 记账成功：显示 toast + 「本月已花XX元，还剩XX元」
- 支持选择账户（从账户列表选择）

### FR-04 账单列表
- 顶部搜索框：按备注关键词搜索
- 时间筛选 Tab：今天 / 本周 / 本月 / 全部
- 分类多选筛选
- 账户筛选（下拉多选）
- 每条记录右侧删除按钮
- 按时间倒序显示

### FR-05 账户管理（新增）
- 支持新增/编辑/删除账户（账户名 + 图标/颜色）
- 预设账户：现金、支付宝、微信、银行卡
- 余额自动计算：根据该账户所有账单收入-支出实时计算余额
- 账单记录关联账户字段

### FR-06 报表
- 日报：当日收支合计 + 支出分类饼图 + 收入分类饼图（并排）
- 月报：当月收支合计 + 支出分类饼图 + 收入分类饼图 + 月份切换
- 月报底部显示收支记录列表

### FR-07 预算提醒
- 用户设置月度总预算（金额）
- 进度条4色：<60%绿 / 60-80%黄 / 80-100%橙 / >100%红
- 支出达 80% 和 100% 各弹窗提醒一次
- 每月1日自动重置

### FR-08 分类
- 预设支出18个：餐饮🍜、交通🚗、购物🛒、娱乐🎮、居住🏠、医疗🏥、教育📚、通讯📱、护肤💄、旅游✈️、运动健身💪、宠物🐶、社交🎁、烟酒🚬、投资📈、汽车🚙、母婴👶、其他📌
- 预设收入6个：工资💼、兼职💻、投资理财📈、被动收入🏠、红包🧧、其他📌
- 用户可新增/编辑/删除自定义分类（预设不可删除）

### FR-09 技术约束
- 纯 localStorage，不依赖任何外部服务
- 单文件 HTML，内嵌 CSS/JS
- 中文 UTF-8，GitHub Pages 托管
- 响应式移动端优先，max-width: 430px
